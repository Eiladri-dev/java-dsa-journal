03 — Concepts & correctness

Read the logic, not just the output

Why start at 1?

Multiplication uses 1 as its identity. Starting at 0 would leave the answer at zero for every N.

The zero case

By definition, 0! = 1. The loop performs no multiplication when N is 0, so the initial value is already correct.

Overflow boundary

A Java int cannot hold 13!. A signed long holds factorials only through 20!.

Future DSA connection

Factorials appear in permutations, combinations, combinatorics, recursive definitions, and backtracking counts.

04 — Your implementation

Original Java solution.

The accumulator is a long so that all values from 0! through 20! fit.

Factorial.java
import java.util.Scanner;

public class Factorial {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter N (0–20): ");
        int n = sc.nextInt();

        if (n < 0 || n > 20) {
            System.out.println("N must be between 0 and 20.");
            return;
        }

        long factorial = 1;
        for (int i = 1; i <= n; i++) {
            factorial *= i;
        }

        System.out.println(n + "! = " + factorial);
    }
}
Range: 0–20Time O(N) · Space O(1)
